# Quiz App

A general knowledge quiz application built with Flutter.

## Features

- 15 questions across Science, Geography, History, and General Knowledge
- Multiple choice answers (4 options per question)
- Instant feedback — correct answers highlighted green, wrong ones red
- Progress bar showing quiz progress
- Live score tracking during the quiz
- Final results screen with grade, percentage, and score breakdown
- Option to retake the quiz or return home
- Quit confirmation dialog

## Screens

| Screen | Description |
|--------|-------------|
| Home | Shows category overview and Start button |
| Quiz | One question at a time with A/B/C/D options |
| Result | Final score, grade (A+–D), percentage, and retry option |

## Getting Started

```bash
cd quiz_app
flutter pub get
flutter run
```

## Build APK

```bash
flutter build apk --release
```

APK: `build/app/outputs/flutter-apk/app-release.apk`
